Las funciones consisten en:
- **DDL (Data Definition Lnaguage):** Define la estructura creando las tablas y demas.
- **DML (Data Manipulation Language):** Manipula los datos para seleccionar o actualización.
- **DCL (Data Control Language):** Controla el acceso de roles y permisos.
- **TCL (Transaction Control Language):** Gestiona las transacciones y su control de pasos.
